# crasher00

**crasher00** es una aplicación web progresiva y autónoma (SPA) diseñada para el seguimiento y optimización de entrenamientos de fuerza y rutinas de gimnasio estructuradas (**Push, Pull, Arm, Leg**) con enfoque científico y analítico.

---

## 🌐 Aplicación Web en Vivo

Puedes acceder directamente a la aplicación alojada en GitHub Pages:
👉 **[https://mugen-houy0u.github.io/crasher00/](https://mugen-houy0u.github.io/crasher00/)**

---

## 🚀 Características Principales

- **Gestión Integral de Rutinas:**
  - Rutinas dedicadas: **Push**, **Pull**, **Arm** y **Leg**.
  - Registro de ejercicios, series, repeticiones, cargas (kg/lbs) y RPE.
- **Temporizador de Descanso Inteligente:**
  - Control de pausas entre series con alertas visuales.
- **Historial y Análisis de Progreso:**
  - Comparativa de sesiones para sobrecarga progresiva real.
  - Registro de observaciones y sensaciones en cada sesión.
- **Privacidad y Persistencia Local:**
  - Los datos se guardan de forma local en tu navegador (`localStorage`).
  - Sin necesidad de servidores externos ni cuentas obligatorias.
- **Importación y Exportación:**
  - Descarga copias de seguridad en formato **JSON**.
  - Exportación de métricas en formato **CSV** para análisis en hojas de cálculo.
  - Opciones de reinicio y restauración total.
- **Diseño Moderno y Responsivo:**
  - Interfaz oscura estilo HUD con estética minimalista.
  - Optimizado para dispositivos móviles y escritorio.
